# Grinko
 AI-Powered Vehicle Diagnostic Tool

Grinko is a CLI and web tool that takes a vehicle symptom described in plain language and returns the most probable fault cause, recommended checks, repair guidance - powered by the NVIDIA NIM API and real fault database.

# The Problem
Mechanics in Ghana and across Africa often diagnose vehicles based on guessworks. Grinko provides a structured, accessible tool that reasons through symptoms systematically without the need for expensive OBD hardware.
